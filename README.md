# Thiranex Website UI Redesign

A modern and responsive website UI redesign created as part of the Thiranex Website UI Redesign task.

## Project Overview

The goal of this project was to redesign an existing website interface with a focus on usability, visual hierarchy, responsive layouts, and a consistent design system.

## Objectives

- Identify usability issues through heuristic evaluation
- Develop a clear visual direction using a mood board
- Create a reusable UI style guide
- Design a high-fidelity desktop homepage
- Create a responsive mobile version
- Improve visual hierarchy, spacing, typography, and navigation

## UX Process

### 1. Heuristic Evaluation

The existing interface was evaluated to identify usability issues related to:

- Visual hierarchy
- Navigation
- Spacing
- Typography
- Responsive design

### 2. Mood Board

The visual direction focuses on:

- Modern
- Professional
- Friendly
- Accessible

### 3. Style Guide

The design system includes:

- Colour palette
- Typography scale
- Primary and secondary buttons
- Form elements
- Cards
- Consistent spacing and corner radius

## Desktop Design

The desktop homepage includes:

- Navigation bar
- Hero section
- Statistics

## Mobile Design

The mobile version includes:

- Responsive navigation
- Mobile hero section
- Stacked CTA buttons
- 2×2 statistics layout

- Responsive CTA
- Simplified footer
